Developed a scalable live streaming server using HLS (HTTP Live Streaming) with automated video encoding, transcoding, and cloud storage integration. Leveraged FFmpeg to encode and segment videos, seamlessly uploading them to AWS S3 using bash scripts for full automation. This project provided valuable insights into video streaming workflows, including challenges in latency, segment management, and optimization techniques. Detailed insights can be found [here](https://medium.com/@gowthamkishore3/from-game-to-screen-demystifying-the-magic-behind-live-streaming-with-hls-f621c758ae28).
