Developed Octorag, an Agentic RAG-based GitHub query assistant for advanced repository exploration and metadata retrieval. Built a RAG system with LangChain, using a NetworkX graph database persisted in ArangoDB.

Integrated OpenAI LLM for dynamic query handling and a Gradio frontend for complex searches beyond GitHub or Google. Added a fallback mechanism to discover newly created repositories when needed.
